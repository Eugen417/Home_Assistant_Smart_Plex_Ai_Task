# 🎬 PYScript Smart Plex Launcher

**Описание:**
Данный скрипт при помощи **Ai Task** сам сканирует библиотеки и их содержимое, управляет устройствами и медиаплеерами, ищет и воспроизводит медиаконтент в указанной в запросе зоне/комнате.

Скрипт выступает интеллектуальным драйвером: он превращает голосовую команду в сложный JSON-запрос к API Plex, автоматически исправляя ошибки распознавания речи (падежи, окончания).

**Возможности:**

* **Команды воспроизведения:** Поддерживает **«Включи»** (с начала) и **«Продолжи»** (Smart Resume — с места остановки или следующая серия).
* **Умный поиск:** Ищет по названию, сезону, серии, альбому, песне, плейлисту, году, жанру, артисту, актёру, режиссеру, студии, **клипам** и даже **настроению**.
* **Сценарии:** Различает запросы «Включи свежее» (новинки без перемешивания) и «Включи любое» (случайный порядок).
* **Автономность:** Автоматически определяет ID библиотек Plex (Auto-Discovery) и кэширует базу данных для мгновенного отклика.
* **Управление железом:** Включает ТВ/Приставку (Apple TV, WebOS, Tizen) и запускает приложение Plex в нужной зоне.

### ⚙️ Требования (Requirements)

Для работы необходимо наличие следующих компонентов:

1. **Plex Media Server:** Установлен и настроен.
2. **Home Assistant:**


* Интеграция **Plex Media Server**.
* Интеграция **Pyscript**.
* Настроенная **Диалоговая Система** (Assist) с подключенным AI (Ollama / Google Gemini).

### 🚀 Установка и Настройка

#### Шаг 1. Установка Pyscript

1. Поместите файл скрипта `plex_smart_launch.py` в папку `/config/pyscript/`.
2. Отредактируйте секцию **НАСТРОЙКИ** в файле:

* `PLEX_URL`: Адрес сервера.
* `PLEX_TOKEN`: Токен авторизации.

> **Как получить токен:** В веб-интерфейсе Plex Server (не HA) нажмите на три точки у любого медиа -> **Информация** -> **Показать XML**. Токен находится в конце URL ссылки в адресной строке.

* `ZONES`: Пропишите ваши устройства.

3. Перезагрузите Pyscript.

#### Шаг 2. Создание Моста (Bridge)

Для коммуникации скрипта с диалоговым ассистентом нужен промежуточный скрипт.
Создайте новый скрипт в Home Assistant (**Настройки -> Автоматизации и сцены -> Скрипты -> Добавить скрипт**) и вставьте этот YAML код:

*Не забудьте дать доступ этому скрипту к Диалоговым системам в настройках Скрипта!*

```yaml
alias: Smart Plex Bridge
description: Мост для передачи команд из ИИ в Pyscript
fields:
  command_text:
    name: Текст команды
    example: включи фильм Аватар
sequence:
  - action: pyscript.plex_smart_launch
    data:
      command_text: "{{ command_text }}"
  - stop: Success
mode: single

```

#### Шаг 3. Инструкция для Диалоговой системы (AI Prompt)

Добавьте этот текст в системную инструкцию вашего AI (Ollama / Gemini) в Home Assistant:

```text
ОБЩИЕ ПРАВИЛА (PLEX):
1. Когда пользователь просит включить фильм/сериал/музыку, ты МОЛЧА и НЕМЕДЛЕННО вызываешь инструмент `script.smart_plex_bridge`.
2. В параметр `command_text` передаешь полную фразу пользователя без изменений.
3. Дождись ответа от инструмента (он вернет "Success").
4. ТОЛЬКО ПОСЛЕ ЭТОГО выдай финальную фразу: "Сэр, Занимаюсь поиском и запуском. Я к вашим услугам."
5. НИКОГДА не отвечай ничего другого. Не пиши текст до вызова инструмента.

```

### 🗣  Тестирование работоспособности через Панель разработчика:


В Панели разработчика враздел Действие (врежиме ввода)
* в поле действия найдите **pyscript.plex_smart_launch**
* в поле Данные действия используйте следующие команды:

1.) **Простой запуск фильма**

```yaml
command_text: включи фильм Джентльмены

```
2.) **Smart Resume (Продолжить просмотр)**

```yaml
command_text: продолжи сериал Доктор Хаус

```
3.) **Точный запуск серии**

```yaml
command_text: включи 3 сезон 5 серию Рик и Морти

```
4.) **Музыкальные клипы**

```yaml
command_text: включи клипы Rammstein (Видеоклипы не работают но включатся песни)

```
5.) **Свежие новинки (Сортировка по дате)**

```yaml
command_text: включи свежую фантастику

```
6.) **Поиск по настроению**

```yaml
command_text: включи веселую музыку

```
7.) **Поиск по актеру**

```yaml
command_text: включи фильм с Брэдом Питтом

```
8.) **Случайный выбор (Shuffle)**

```yaml
command_text: включи любую комедию

```
9.) **Поиск по году**

```yaml
command_text: включи боевик 2024 года

```
10.) **Музыкальный альбом**

```yaml
command_text: включи Linkin Park альбом Meteora

```
